영상의 텍스트 설명

Listener.AI에 샘플 대화 음원을 불러와 AI 처리를 실행합니다. 처리가 끝나면 저장된 회의를 열어 회의 요약과 발화자별 대화록을 확인하고, 이 회의에서 무엇을 설계하는지 질문합니다. 실제 답변은 리모컨을 설계하는 팀이며 구체적인 요구사항은 아직 논의하지 않았다는 내용입니다. 영상은 소리 없이 재생되며 처리 대기 시간을 줄이고 실제 화면 일부를 정지 화면으로 보여줍니다.

가지고 있는 AI 계정 연결

Gemini, OpenAI, Soniox 등 지원하는 서비스의 API 키를 연결하세요. ChatGPT 로그인은 요약과 AI 채팅 같은 텍스트 작업에 사용할 수 있습니다.

음성 전사와 실시간 자막에는 별도 제공자 설정이 필요하며, API 사용 요금은 해당 제공자에서 발생할 수 있습니다. ChatGPT 로그인에 음성 처리가 포함되지는 않습니다.

팀이 쓰는 도구로 이어서

설정한 Notion과 Slack으로 회의 노트를 보내세요. Google Drive를 연결하면 회의 폴더를 동기화할 수 있습니다. 연동은 선택 사항입니다.

시작하기 전에.

앱을 사용하려면 무엇이 필요한가요?

macOS 또는 Windows 컴퓨터와 AI 제공자 연결이 필요합니다. 앱 설치 후 설정에서 요약에 사용할 AI와 음성 전사 제공자를 선택하세요. 서비스에 따라 API 키 또는 ChatGPT 로그인이 필요합니다.

오프라인에서도 AI 처리가 되나요?

녹음과 기록 보관은 내 컴퓨터에서 이루어집니다. AI 전사, 요약, 채팅에는 인터넷 연결이 필요하며 오디오나 텍스트가 선택한 제공자에게 전송됩니다. 로컬 저장이 로컬 AI 처리를 의미하지는 않습니다.

별도 구독이 필요한가요?

Listener.AI는 오픈 소스로 제공됩니다. 연결한 AI 서비스의 API 이용료와 계정 조건은 각 제공자의 정책을 따릅니다. ChatGPT 로그인을 사용해도 음성 전사 제공자의 API 비용은 별도로 발생할 수 있습니다.

내 기록을 다른 곳으로 보낼 수 있나요?

회의 노트는 로컬에 보관하며 내보내기와 검색을 지원합니다. Notion, Slack, Google Drive를 연결한 경우 해당 서비스로 기록을 전송할 수 있습니다. 회의 참여자의 동의를 확인하고 필요한 내용만 공유하세요.
